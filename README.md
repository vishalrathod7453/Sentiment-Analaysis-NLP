# Sentiment-Analaysis-NLP

#📌 Project Overview

This Sentiment Analysis Project uses Machine Learning and Natural Language Processing (NLP) techniques to analyze text and classify sentiments as Positive, Negative, or Neutral. The project helps understand customer opinions, social media feedback, product reviews, and user sentiments from textual data.

# 🚀 Features
- Text preprocessing and cleaning
- Tokenization and stopword removal
- Sentiment classification (Positive, Negative, Neutral)
- Machine Learning-based prediction
- Interactive user input for sentiment checking
- Data visualization of sentiment distribution
- Easy deployment using Streamlit
